Suppose we have **3 pollution monitoring stations**:

```text
Station A
Station B
Station C
```

And we record:

```text
PM2.5
PM10
NO2
Temperature
Humidity
...
```

every hour.

For one 24-hour period, the data conceptually looks like:

```text
              24 hours
          ───────────────────────>
Station A   [data][data][data]...
Station B   [data][data][data]...
Station C   [data][data][data]...
```

But some pollution values are missing:

```text
Station A   [PM2.5] [PM2.5] [ ? ] [PM2.5] ...
Station B   [PM2.5] [ ?   ] [PM2.5] [PM2.5] ...
Station C   [PM2.5] [PM2.5] [PM2.5] [ ?   ] ...
```

The job of CTDI is:

```text
OBSERVED DATA + MISSINGNESS INFORMATION
                  ↓
             CTDI MODEL
                  ↓
        ESTIMATED MISSING VALUES
```

The paper represents the missing/observed state using a binary mask:

```text
1 = observed
0 = missing
```

and feeds the incomplete tensor into the network.
