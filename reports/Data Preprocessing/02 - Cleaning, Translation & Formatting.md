## 1. Overview

Raw government datasets arrive with multiple formatting challenges:
- **Bilingual Headers & Chinese Text**: Traditional Chinese characters in notices, street names, and column headers.
- **Non-Standard Time Conventions**: Hours numbered `01` to `24` with dates formatted as `D/M/YYYY`.
- **String Missingness Codes**: Entries such as `"N.A."`, `"***"`, `"# data incomplete"`, or whitespace.
- **Irrelevant Network Additions**: Newer stations commissioned mid-study.

This document details the exact cleaning and normalization steps that convert raw CSVs into clean, machine-learning-ready tables.

## 2. Resolving Chinese Characters and Non-English Text

### 2.1 The Two Rules
1. **Zero foreign text in neural network tensors**: Neural layers process pure floating-point numbers (`float32`).

## 3. Date & Hour Harmonization

### 3.1 The EPD 24-Hour Convention
Hong Kong EPD records time in 1-indexed hours:
- `HOUR = 1` represents the 1-hour interval from **00:00 to 01:00** (hour ending 01:00).
- `HOUR = 2` represents **01:00 to 02:00**.
- ...
- `HOUR = 24` represents **23:00 to 24:00** (hour ending midnight).

### 3.2 Conversion to Continuous ISO Timestamps
To convert to standard 0-indexed ISO datetime:
$$\text{timestamp} = \text{pd.to\_datetime}(\text{DATE}, \text{format}='\%d/\%m/\%Y') + (\text{HOUR} - 1) \times \text{timedelta}(\text{hours}=1)$$

```python
df["timestamp"] = (
    pd.to_datetime(df["DATE"], format="%d/%m/%Y") 
    + pd.to_timedelta(df["HOUR"].astype(int) - 1, unit="h")
)
```

#### Timeline Bounds Verification:
- **First Timestamp**: `2019-01-01 00:00:00`
- **Last Timestamp**: `2021-12-31 23:00:00`
- **Total Continuous Hours**: Exactly **26,304** hours per station.
- **Monotonicity**: Continuous, strictly increasing ($t_{k+1} - t_k = 1\text{ hour}$), zero duplicate timestamps.

## 4. Numeric Sanitization

### 4.1 Handling Missingness Flags
In raw government exports, missing values appear as text strings rather than standard numerical blanks. Our cleaning routine coerces them into standard IEEE 754 `NaN`:

```python
def sanitize_numeric_column(series: pd.Series) -> pd.Series:
    # 1. Strip whitespace
    s = series.astype(str).str.strip()
    # 2. Replace known string flags with standard NaN
    s = s.replace(["N.A.", "NA", "***", "#", "-", "", "nan", "None"], np.nan)
    # 3. Coerce to float32
    return pd.to_numeric(s, errors="coerce").astype(np.float32)
```

### 4.2 Physical Range Validation
Following conversion, all values are verified against physical sanity bounds:
- Pollutants ($\text{PM}_{2.5}, \text{PM}_{10}, \text{NO}_2, \text{O}_3, \text{SO}_2$): Must satisfy $x \ge 0.0\ \mu\text{g/m}^3$.
- Temperature: $-5.0^\circ\text{C} \le T \le 45.0^\circ\text{C}$.
- Relative Humidity: $0.0\% \le \text{RH} \le 100.0\%$.
- Surface Pressure: $900.0\text{ hPa} \le P \le 1050.0\text{ hPa}$.
- Wind Speed: $\text{WS} \ge 0.0\text{ m/s}$.
- Rainfall: $\text{RAIN} \ge 0.0\text{ mm}$.
