## 2. Work Executed & Engineering Architecture

### 2.1 Streaming Extraction Engine (`src/preprocessing/extract_complete_traffic.py`)
- Leveraged DATA.GOV.HK monthly archive packaging (`url=http%3A%2F%2Fresource.data.one.gov.hk%2Ftd%2Fspeedmap.xml&time=YYYYMM01`).
- Implemented high-throughput streaming architecture downloading and parsing monthly archives directly in memory without uncompressing 100+ GB of raw XML to disk.
- ElementTree XML streaming parser extracting:
  - `timestamp`: Snapshot capture time converted to ISO-8601 with Asia/Hong_Kong timezone alignment.
  - `link_id`: Discrete road link identifier (string).
  - `traffic_speed`: Float speed in $\text{km/h}$.
  - `traffic_congestion`: Cleaned categorical saturation string (`TRAFFIC GOOD`, `TRAFFIC AVERAGE`, `TRAFFIC BAD`).
  - `region`: Geographical territory code (`HK`, `KLD`, `KLT`, `NTW`, `NTE`).
  - `road_type`: Functional classification code (`URBAN`, `HIGHWAY`, `RURAL`, etc.).
- Persisted to 36 monthly partitions (`data/interim/traffic/monthly/traffic_speedmap_YYYYMM.parquet`) totaling ~725 MB with Snappy compression.
- Established dataset symlink `data/interim/traffic/clean_traffic_speedmap_complete.parquet` pointing directly to `monthly/`, enabling seamless PyArrow multi-file scanning.
