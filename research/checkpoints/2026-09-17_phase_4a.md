   $$\mathbf{X}_{\text{obs}}, \mathbf{M} \longrightarrow \text{ContextBuilder} \longrightarrow C \longrightarrow \text{SLM} \longrightarrow \mathbf{z}_C \longrightarrow \text{Conditional Diffusion} \longrightarrow \hat{\mathbf{X}}_{\text{miss}}$$

7. Establish an absolute programmatic firewall preventing target leakage of hidden ground truth values ($\mathbf{X}_{\text{hidden}}$).
8. Design the systematic ablation protocol isolating the semantic contribution of the SLM.
9. Implement modular architecture scaffolding code in `src/context/` with 100% type annotations and unit test coverage.
10. Ensure zero model training, zero parameter tuning, and absolute immutability of Phase 1–3 artifacts and raw data.

## 2. Work Executed & Architecture Specifications

### 2.1 Feature Extraction & Thresholding Logic (`src/context/context_features.py`)
- Implemented numerical feature aggregators for 24-hour window slices ($24 \times 13$).
- Documented official HKO and international meteorological threshold mappings:
  - **Temperature**: Intensely cold ($<8^\circ\text{C}$), Cold ($\le 12^\circ\text{C}$, HKO Cold Warning), Cool ($12\text{--}18^\circ\text{C}$), Mild ($18\text{--}24^\circ\text{C}$), Warm ($24\text{--}28^\circ\text{C}$), Hot ($28\text{--}33^\circ\text{C}$), Very Hot ($\ge 33^\circ\text{C}$, HKO Very Hot Warning).
  - **Relative Humidity**: Very Dry ($<40\%$), Dry ($40\text{--}59\%$), Comfortable ($60\text{--}79\%$), Humid ($80\text{--}89\%$), Very Humid ($\ge 90\%$).
  - **Rainfall**: No rain ($<0.1\text{ mm}$), Light ($0.1\text{--}5\text{ mm/h}$), Moderate ($5\text{--}15\text{ mm/h}$), Heavy ($15\text{--}30\text{ mm/h}$), Torrential Downpour ($\ge 30\text{ mm/h}$, HKO Amber/Red/Black Rainstorm scale).
  - **Wind**: Beaufort scale in $\text{m/s}$ (Calm $<1.5$, Light breeze $1.5\text{--}3.3$, Moderate breeze $3.4\text{--}7.9$, Fresh wind $8.0\text{--}10.7$, Strong wind $10.8\text{--}13.8$, Gale $\ge 13.9$). Compass directions partitioned into Continental Outflow ($0^\circ\text{--}112.5^\circ$, $337.5^\circ\text{--}360^\circ$) vs. Maritime Inflow ($112.5^\circ\text{--}292.5^\circ$) vs. Stagnant Inversion ($<1.5\text{ m/s}$).
  - **Traffic**: Empirical corridor speed ($<40$, $40\text{--}60$, $>60\text{ km/h}$) and congestion saturation ($<0.10$, $0.10\text{--}0.25$, $>0.25$).
  - **Missingness Profiler**: Computes missing cell count, percentage, pattern (sporadic vs. contiguous block gap), and list of affected pollutant channels.

### 2.2 Serialization & Formatting Engine (`src/context/context_serializer.py`)
- Implemented multi-format serialization:
  - **Narrative Format (Primary)**: Natural English atmospheric paragraph designed for causal/encoder SLMs.
  - **Structured Key-Value (Alternative)**: Dense, delimiter-separated format maximizing token efficiency.
  - **Pure JSON**: Deterministic dictionary serialization for programmatic inspection.

### 2.3 Environmental Context Builder Orchestrator (`src/context/context_builder.py`)
- `EnvironmentalContextBuilder` class:
  - Enriches window metadata with station catalog (station name, type, district, lat/lon, sampling height).
  - Seamlessly accepts either `np.ndarray` of shape $(24, 13)$ or parquet `pd.Series` / row dicts.
  - Implements batch processing: `build_batch_prompts()`.
  - Implements `audit_leakage()` static validation checking that hidden pollutant values do not appear in generated prompts.

### 2.4 SLM Context Encoder Architecture (`src/context/slm_encoder.py`)
- `BaseSLMContextEncoder(nn.Module)`:
  - Abstract interface defining `forward(prompts) -> z_C`.
  - Pooling mechanisms: Masked Mean Pooling (over non-padding tokens), Last-Token Pooling, and Query-based Attention Pooling.
  - Trainable linear projection head $\mathbf{W}_p \in \mathbb{R}^{d_{\text{diff}} \times d_{\text{slm}}}$ with LayerNorm.
  - Frozen backbone parameter management (`param.requires_grad = False`).
- `MockSLMContextEncoder`:
  - Deterministic pseudo-embedding generator using SHA-256 digests for lightweight testing without downloading HuggingFace checkpoints.
- `HuggingFaceSLMContextEncoder`:
  - Production architecture specification for loading pre-trained causal/encoder models (e.g. Qwen2.5-0.5B, Llama-3.2-1B).
