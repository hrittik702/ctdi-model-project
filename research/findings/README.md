# Scientific Findings, Boundaries & Unresolved Questions

This directory documents empirical discoveries, confirmed scientific facts, negative results (dead ends), living open questions, and research limitations.

---

## Documents in This Section

1. **[Confirmed Findings](confirmed_findings.md)**: Verified empirical facts backed by direct citations, code runs, or official government archives.
2. **[Negative Findings](negative_findings.md)**: Critically important documentation of tested approaches that failed, proved unviable, or were refuted. Prevents redundant investigations.
3. **[Unresolved Questions](unresolved_questions.md)**: Living list of active scientific questions with current evidence, impact, and next steps.
4. **[Research Limitations](research_limitations.md)**: Methodological, physical, computational, and archival boundary limitations.
