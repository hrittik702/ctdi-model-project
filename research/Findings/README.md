# Scientific Findings, Boundaries & Unresolved Questions

This directory documents empirical discoveries, confirmed scientific facts, negative results (dead ends), living open questions, and research limitations.

---

## Documents in This Section

1. **[Confirmed Findings](Confirmed%20Research%20Findings.md)**: Verified empirical facts backed by direct citations, code runs, or official government archives.
2. **[Negative Findings](Negative%20Findings%20&%20Dead%20Ends.md)**: Critically important documentation of tested approaches that failed, proved unviable, or were refuted. Prevents redundant investigations.
3. **[Unresolved Questions](Living%20Unresolved%20Questions.md)**: Living list of active scientific questions with current evidence, impact, and next steps.
4. **[Research Limitations](Research%20Boundaries%20&%20Limitations.md)**: Methodological, physical, computational, and archival boundary limitations.
